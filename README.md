# 🐾 PetShop Amigo Fiel - Sistema Web (Fase 1)

Projeto desenvolvido para a disciplina de **Fundamentos de Sistemas Web** (Graduação PUCRS Online). Consiste na estruturação front-end de um sistema web para um petshop, desenvolvido exclusivamente em **HTML puro** (sem estilização CSS ou scripts JavaScript).

* **Repositório (Código-Fonte):** [Acesse o código aqui](https://github.com/ThiagoEletroDev/projeto-petshop)

## 📋 Funcionalidades e Estrutura da Página
A aplicação foi organizada utilizando tags semânticas do HTML5 para facilitar a navegação e a estruturação do conteúdo:

* **Cabeçalho (`<header>`):** Apresenta a identidade visual do petshop e o menu de navegação rápido entre as seções da página.
* **Catálogo de Produtos (`<main>`):** Dividido em **3 categorias** distintas, exibindo **2 produtos em cada categoria** com foto ilustrativa, descrição detalhada e valor unitário.
* **Serviços (`<section id="servicos">`):** Lista os serviços oferecidos pelo estabelecimento, informando a descrição de cada atendimento, o valor e a disponibilidade do serviço de **tele-busca**.
* **Rodapé (`<footer>`):** Contém as informações legais de autoria, direitos reservados e dados de contato do petshop.
